    Field guide

    1. Replay an observation.

      Choose a case and select Next event. The ledger, priority and briefing update together.

    2. Trace the judgement.

      Select a supporting event to find the observation. Switch to Service owner to see the operational handover. Open the assessment details to inspect the model and rule reasoning.

    3. Make a decision.

      Record a disposition and save it at the current event. Download the Markdown handover to retain the evidence and review.

    The cases are fictional. Replay advances through recorded observations. Decisions stay in this browser and apply only to their saved event position.
